## Why

Singles calls have two scores, but the current scoreboard displays a doubles server digit. The portrait Android controller needs a verified upgrade package.

## What Changes

- Add a dedicated singles composition in firmware and Android. Freeze the accepted doubles pixels and wire protocol.
- Verify and package the current portrait controller and a signed offline firmware candidate.

## Capabilities

### Modified Capabilities

- `shared-display-assets`: define and verify mode-dependent portrait bands.

## Impact

Shared layout and fixtures, ESP32 renderer, Android preview and release verification. No scoring, DMA, or OTA trust change.
