# Archived OpenSpec changes

These directories preserve decisions and original checklists. Unchecked tasks
in superseded changes do not represent current requirements or hardware
permission.

The 2026-11-23 archives were moved without applying their old delta specs:

- `implement-display-rendering`: the 64×32 renderer and divider were superseded.
- `implement-ble-wiring`: the original rally commands and sync checklist were superseded.
- `full-game-undo-court-controller`: shipped in the portrait line; landscape later reduced the journal and removed the controller's Undo key.

Consult [the current product specifications](../../../docs/specs) rather than
applying a historical delta to the landscape implementation.
